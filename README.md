# OMRAAJANS360 V2

Premium OMRAAJANS360 web sitesi başlangıç paketi.

## Kurulum

```powershell
npm install
npm run dev
```

Tarayıcı: `http://localhost:3000`

## Sayfalar

- `/` Ana Sayfa
- `/drone-cekimi`
- `/qr-menu`
- `/hakkimizda`
- `/iletisim`

## Marka dosyaları

- `src/components/BrandLogo.tsx` — seçilen OMR yönüne göre vektörel logo
- `src/app/icon.svg` — favicon / uygulama sembolü

## Görseller

`public/images/` altında paketle birlikte gelir. Kullanılan görseller OMRAAJANS360 tasarım çalışmasından türetilmiş geçici marka görselleridir; gerçek OMRAAJANS360 çekimleri oluşmaya başladığında aynı dosya adları korunarak kolayca değiştirilebilir.

## Canlıya geçmeden önce gerekli son bilgiler

- WhatsApp/telefon numarası
- E-posta adresi
- Instagram kullanıcı adı
- Alan adı DNS/Vercel bağlantısı
- Teklif formunun gerçek e-posta veya API bağlantısı
